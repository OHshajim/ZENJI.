# ZENJI

Anime-inspired streetwear e-commerce frontend.

## Tech Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Lucide React

## Features
- Responsive editorial storefront
- Local typed product catalog
- Search, filtering, and sorting
- Product details and gallery
- LocalStorage cart persistence
- Responsive navigation and search overlay
- Accessible controls and reduced-motion support
- SEO metadata

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

This is a frontend assessment implementation. Checkout, backend, authentication, payments, and email delivery are intentionally mocked or local-only.
